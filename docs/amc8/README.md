# 原创 AMC8 风格训练 · 每周六30分钟

这是“每周一次”的精简新版，不是原先每天30分钟的版本。
制作与资料核验日期：2026-11-07（Asia/Shanghai）。

## 给家长的一句话

**只在每周六安排一次，总计30分钟；周一至周五和周日没有训练任务。**
3分钟概念/小例子 + 20分钟独立做5题 + 7分钟精选复盘。
没有额外诊断、另外加的周测、书架作业、通知或推送。缺席就顺延，不产生补课债务。

## 在MacBook Air使用

1. 下载ZIP、双击解压，打开 `AMC8每周30分钟.html` 或 `index.html`，用Safari/Chrome均可。两个文件内容相同，选一个固定使用，别反复改名/移动。
2. 无需安装、账户、服务器或网络。做题内容、样式、SVG、程序都在一个HTML里；外部参考资料链接需联网。
3. 主按钮是「开始本周的30分钟」。首次进入第1周5题起点观察，**不再另做18题诊断**。
4. 准备草稿纸，不用计算器。3分钟短讲结束自动进入20分钟作答，作答结束自动交卷，余下7分钟复盘。
5. 只挑1–2道错题或最犹豫的题讲清方法，不要求7分钟看完所有解析。完成复盘可保留本周，下次周六重练；也可手动选下一周。

开始后**不暂停**。切标签、关页、电脑休眠仍按原截止时刻计时。重新打开会恢复选择；超过作答截止会自动交卷。30分钟总时段过后不再补足复盘计时，也不安排第二份补测。主动提前交卷可把未用时间用于复盘，仍在原来的30分钟以内。未准备好就不开始，缺席后顺延即可。

## 时间预算与使用边界

| 环节 | 每周时间 | 内容 |
|---|---:|---|
| 概念/小例子 | 3分钟 | 用一个小例子唤醒方法，不含本次题目答案 |
| 独立尝试 | 20分钟 | 固定5道，代表不同关键策略；可以标记/跳过 |
| 精选复盘 | 7分钟 | 只讲透1–2题，记录一个改法 |
| 合计 | **30分钟** | 每周六只做这一份 |

第4、8、12周是**替换本周主题题组的混合回看**，仍是同一份5题、同一个30分钟，不加测。首周起点观察融入本周5题，不另计时。工作日及周日没有作业。

这是**低负担重点训练、兴趣与基础维护**，不是完整AMC8备考课程。12次合计仅6小时，不能承诺全面掌握全部考法或取得高分。没有假定孩子的年龄、年级、数学基础或目标分；若基础薄弱，可在下次周六重练同一周、画图或讲解，不赶进度、不追题量。

涉及七个大方向，但复杂空间想象、复杂图表、难题技巧等没有系统覆盖。“重点轮转”不等于穷尽题型。5题结果不用于官方分数预测，也不把孩子按一次小样本表现定级。

## 内容范围

- 12份周训练，每份5题，共60个安排题位。
- 49道不同的原创题，其中46道来自已独立验算的原原创库、3道新补代表题（估算、三角形角度、条件排除），均再次独立验算。
- 另外11个题位是明确标记的过往重点回看，因此不是60道互不相同的新题。
- 34种方法结构，每周5题的结构不同，不把旧6份日练堆进一张卷。
- 每题5个不同选项，唯一正确答案，中文解释和「本题关键方法」；含三角形、L形及角度示意SVG，标注不按比例。
- 原2145题大库和旧日练版本不在本网站入口或当前ZIP中曝光，不是新版的主卖点。

## 间隔回看与错题

第2周起仍按计划回看更早的重点。到期的答错或未作答可以换进当次5题，但不会加题：

- 已经在本周5题里：合并标记，不再加题。
- 不在本周、方法也不与其余题重复：普通周最多替换2题，第4、8、12周阶段回看最多替换1题。被换下的原定重点会在开始前写明，并顺延，不消失成没说明的空白。
- 没有合适的题：保留原计划。
- 题库没有这些题的新编变式。换入的仍是同一道原题，并保留它来自哪一周。再做对只说明那一次做对，不能说已经记住。
- 家长可以把最多2道标成下次换入。同一天不会立刻重做，要到另一个日期才进入周六的5题。

每周始终5题、30分钟，不另加错题测试，也不超过5题。只从更早周次、更早日期选取。在更晚的两个不同日期分别答对，才标成已巩固。错题本是记录，不是必须清空的作业。答错和未作答分开记。原因默认「未标注」，不会按分数或用时猜测。

## 周六参考安排与进度

默认参考开始日为 **2026-11-07（周六，Asia/Shanghai）**，可在「家长与资料」改成另一个周六。后续参考周六每次相隔7天。

周次**始终手动**选择或在复盘后推进；参考日期不会自动打卡，也不会因错过日期给孩子判欠课。一次没空就顺延，不必补做前面的所有周；基础弱也可重复原周。

## 本机记录能还原什么

做题过程存在这台浏览器的 `amc8-weekly30-v3`（schema 3）。每次操作后写入。刷新或关闭后再打开，会接着原来的选项和操作记录，不会把同一次选择再记一遍。

一次交卷会单独留下，重做不会盖掉上一次。能还原的是：

- 交卷日期、周次，以及每一题当时的题干、选项、主题、题号。
- 第一次选择和最后选择；中途的改选、清空、标记、未答就跳过、切题和返回。
- 是自己交卷还是到时自动交卷；答对、答错、未作答分开。
- 估计的在屏时间：只有页面可见并且窗口在前面时才累计。切到别的窗口、锁屏或关闭都不算。这不是实际思考时间。
- 交卷后自己选的原因。不选就是「未标注」。

不能还原的是：具体按键、屏幕、声音、剪贴板、姓名和邮箱。旧的 schema 2 进度会先原样备份到 `amc8-weekly30-v2-backup`，再迁入；已经完成的周次保留。迁入之前没有记下的点击和在屏时间显示「未记录」，不会编造。更早的每日版 `amc8-studio-v1` 不迁入，也不当成每周完成。

记录只在同一浏览器、同一站点来源。排版器和练习页同在一个 GitHub Pages 域名下，但存储名不同，不会写进排版器。清除浏览器网站数据会丢失。本机空间不够时，会先把较早的操作收成摘要，最终答案仍留着；仍然写不进去就停在内存里，并提示导出，不悄悄丢掉当前答案。

导入上限 5MB。会检查题号、5题、选项、周六日期、3+20+7 和操作记录；不执行文件里的内容。异常或过大的文件会被拒绝。覆盖前需要确认。

## 放到 GitHub 是家长手动备份，不是自动同步

做题的 30 分钟里不上传。页面不能替任何人登录 GitHub，也不能在网页里保存令牌，所以没有跨设备自动同步。可靠的底子仍是本机自动保存和导出 JSON。

家长如果要把答题记录放到这个公开仓库：

1. 在「家长与资料」导出 JSON，文件名用 `latest.json`。
2. 用自己已登录、且能写这个仓库的 GitHub 账号，打开上传页，把文件放到 `amc8-progress/latest.json`。不要放进 `docs/amc8`，那样会变成练习网页上的公开文件。
3. 在另一台浏览器的「家长与资料」点击「从仓库读入进度」。只有这一下才会读取，并要确认才覆盖本机。

仓库是公开的。上传之后，知道地址的人可以读到答题记录。可以放答题过程，不要放密码、令牌、姓名或邮箱。这和自动保存不是一回事。自动写入 GitHub 需要令牌或单独的登录服务，这个静态网页没有。
