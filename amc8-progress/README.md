# 答题进度备份

这个目录不是每周练习页面。GitHub Pages 只发布 `docs/`，所以放在这里的文件不会出现在练习网址下面。

`latest.json` 由家长自己上传，网站不会自动写入。

1. 在练习页「家长与资料」导出 JSON。
2. 用已经登录、并且能写这个仓库的 GitHub 账号，把文件上传为 `amc8-progress/latest.json`。
3. 在另一台浏览器打开练习页，到「家长与资料」点击「从仓库读入进度」。

这不是自动同步。孩子的 30 分钟里不需要做这些。

仓库是公开的，上传后知道地址的人可以读到答题记录。文件里不要写姓名、邮箱、密码或令牌。测试用的假记录不要提交到这里。
