# 原创 AMC8 风格训练 · 每周六30分钟

这是“每周一次”的精简新版，不是原先每天30分钟的版本。
制作与资料核验日期：2026-11-07（Asia/Shanghai）。

## 给家长的一句话

**只在每周六安排一次，总计30分钟；周一至周五和周日没有训练任务。**
3分钟概念/小例子 + 20分钟独立做5题 + 7分钟精选复盘。
没有额外诊断、另外加的周测、书架作业、通知或推送。缺席就顺延，不产生补课债务。

## 在MacBook Air使用

1. 下载ZIP、双击解压，打开 `AMC8每周30分钟.html` 或 `index.html`，用Safari/Chrome均可。两个文件内容相同，选一个固定使用，别反复改名/移动。
2. 无需安装、账户、服务器或网络。做题内容、样式、SVG、程序都在一个HTML里；外部参考资料链接需联网。
3. 主按钮是「开始本周的30分钟」。首次进入第1周5题起点观察，**不再另做18题诊断**。
4. 准备草稿纸，不用计算器。3分钟短讲结束自动进入20分钟作答，作答结束自动交卷，余下7分钟复盘。
5. 只挑1–2道错题或最犹豫的题讲清方法，不要求7分钟看完所有解析。完成复盘可保留本周，下次周六重练；也可手动选下一周。

开始后**不暂停**。切标签、关页、电脑休眠仍按原截止时刻计时。重新打开会恢复选择；超过作答截止会自动交卷。30分钟总时段过后不再补足复盘计时，也不安排第二份补测。主动提前交卷可把未用时间用于复盘，仍在原来的30分钟以内。未准备好就不开始，缺席后顺延即可。

## 时间预算与使用边界

| 环节 | 每周时间 | 内容 |
|---|---:|---|
| 概念/小例子 | 3分钟 | 用一个小例子唤醒方法，不含本次题目答案 |
| 独立尝试 | 20分钟 | 固定5道，代表不同关键策略；可以标记/跳过 |
| 精选复盘 | 7分钟 | 只讲透1–2题，记录一个改法 |
| 合计 | **30分钟** | 每周六只做这一份 |

第4、8、12周是**替换本周主题题组的混合回看**，仍是同一份5题、同一个30分钟，不加测。首周起点观察融入本周5题，不另计时。工作日及周日没有作业。

这是**低负担重点训练、兴趣与基础维护**，不是完整AMC8备考课程。12次合计仅6小时，不能承诺全面掌握全部考法或取得高分。没有假定孩子的年龄、年级、数学基础或目标分；若基础薄弱，可在下次周六重练同一周、画图或讲解，不赶进度、不追题量。

涉及七个大方向，但复杂空间想象、复杂图表、难题技巧等没有系统覆盖。“重点轮转”不等于穷尽题型。5题结果不用于官方分数预测，也不把孩子按一次小样本表现定级。

## 内容范围

- 12份周训练，每份5题，共60个安排题位。
- 49道不同的原创题，其中46道来自已独立验算的原原创库、3道新补代表题（估算、三角形角度、条件排除），均再次独立验算。
- 另外11个题位是明确标记的过往重点回看，因此不是60道互不相同的新题。
- 34种方法结构，每周5题的结构不同，不把旧6份日练堆进一张卷。
- 每题5个不同选项，唯一正确答案，中文解释和「本题关键方法」；含三角形、L形及角度示意SVG，标注不按比例。
- 原2145题大库和旧日练版本不在本网站入口或当前ZIP中曝光，不是新版的主卖点。

## 间隔回看与错题

第2周起末尾1题按计划回看更早一周的重点。若有适合的过往错题，则：
- 已在本周题组中：合并标记，不再加题；
- 尚不在本周且不重复本周其它关键方法：替换末尾题；
- 无合适题：保留原计划回看。

每周始终5题，不另加“错题测试”，也不会超过6题上限。只从更早周次和更早日期的错题选取；两个后续不同日期独立答对才标记为已巩固。错题本是记录，不是必须清空的作业列表。重复熟题的成绩不能当作未见题水平。

## 周六参考安排与进度

默认参考开始日为 **2026-11-07（周六，Asia/Shanghai）**，可在「家长与资料」改成另一个周六。后续参考周六每次相隔7天。

周次**始终手动**选择或在复盘后推进；参考日期不会自动打卡，也不会因错过日期给孩子判欠课。一次没空就顺延，不必补做前面的所有周；基础弱也可重复原周。

## 本机存储、旧版兼容与迁移

- 新存储键为 `amc8-weekly30-v2`；旧版 `amc8-studio-v1` 保持原样，不静默迁移。
- 新版只认每周30分钟的schema 2进度。导入旧版schema 1会明确拒绝，不能将旧日练/诊断完成误认为本周完成。
- 同一设备的Safari、Chrome、离线文件与线上GitHub Pages分别存储。可在「家长与资料」导出/导入新版JSON迁移。
- 导入上限5MB，验证题号、5题长度、选项、周六日期、3+20+7计时结构等，只解析JSON、不执行内容；覆盖前确认。清除新版数据也需确认，不删除旧版数据或已下载备份。
- Safari的本地`file://`存储可能受设置限制。失败会提示，当前仍能在内存做题，关闭前必须导出JSON。文件改名/移动、清理浏览器数据也可能影响读取原进度。
- 不采集姓名/邮箱，无账户、广告、网络追踪或自动上传。导出的JSON含学习记录，家长自行保存，**不要提交到公开仓库**。
- 这是诚实自学工具，不是防作弊系统；检查离线源码能读到答案。
